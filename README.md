# Icon Overlay App

### User Guide: 

The icon overlay app allows you to display an icon selected from a series of icons.  The app is "always on top", so will appear over other application windows, allowing you to overlay icons on top of powerpoints, visualisers, etc.

To **select** a particular icon, you can either:

1) **mouse-over** the icon, and use the **scroll-wheel**, or **drag** up or down with two fingers on the trackpad, to rotate through the available icons.

2) or **click** on the icon, and **press the key** matching the first letter of the **icon's name**.  If there is more than one icon starting with the same letter, press the corresponding key again until the desired icon is displayed.

To **resize** the window, you can either:

1) **mouse-over** the icon, holding down the **control (CTRL) key** whist using the **scroll wheel** or using two fingers on the trackpad.  Up will increase the size, and down will decrease the size.

2) or **click** onto the icon, and then on the **keyboard** press the **"+" key** to enlarge, or the **"-"** to reduce the size of the icon.


### Notes:

* The icon overlay app builds the available set of icons and corresponding key bindings each time it is launched.  
* If you want to add new icons or remove existing icons, simply add or remove their 
  associated file from the "icons" folder.
* The letter associated with each icon is the same as the first letter of its file name, 
  so name each file appropriately.
